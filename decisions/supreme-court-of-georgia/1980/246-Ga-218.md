# Green v. Green

## Majority (Jordan, Presiding Justice.)

Jordan, Presiding Justice.
This is an appeal from an order dismissing a cross complaint relating to marital property in a divorce action which was previously dismissed by consent of the parties.
This appeal is dismissed for failure to comply with the provisions of Code Ann. Par. 6-701.1 (Ga. L. 1979, pp. 619, 620).
Appeal dismissed.
All the Justices concur, except Hill, J, who dissents.
Johnny Green, pro se.
