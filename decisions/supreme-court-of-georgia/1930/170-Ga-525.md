# Elliott v. Blackmon

## Majority (Gilbert, J.)

Gilbert, J.
The exception is to a judgment refusing to set aside a judgment. In an equitable proceeding Blackmon obtained a judgment against Elliott. Elliott filed a motion to set aside the judgment. On conflicting evidence the court did not err in denying the motion.
Judgment affirmed.
All the Justices concur.
